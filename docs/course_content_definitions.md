## Learning Activities
1. Reading
    - Description: Generated reading curriculum. This is where the learners will do the majority of learning. Length should depend on how in-depth the learner wants to go into the material -- more depth should yield longer, more detailed readings. Should include in-line visual aids (if user selected) to help illustrate concepts. Should target between 1,000 and 2,000 words.
    - Frequency: Should be the majority of module content, but try to separate reading activities by other types of activities, like videos or quizes.
2. Video
    - Description: Embedded Youtube videos of instructional materials. Should target under 20 minute videos.
    - Frequency: At most one per module.
3. Essay
    - Description: An LLM-reviewed essay question with a one paragraph response. LLM reviewer should give real feedback on answers that match the users select feedback tone.
    - Frequency: At least one per course.
4. Project
    - Description: A hands-on project for the user to perform -- could be a coding excercise, a quick DIY, or other hands-on task. Project descriptions should provide the users with the task, any requirements or materials they might need, and step-by-step guide on how do it. Only necessary in courses with content that makes sense in a "hands-on" context.
    - Frequency: At least one per course. Only appears within the last two modules of a course
5. Discussion
    - Description: A back-and-forth chat with an LLM about a course concept. Should be at most 5 chat interactions, target around 3.
    - Frequency: Once per course.
6. Assessment
    - Description: End of course knowledge check. 10 to 15 questions about the whole course materials. Not graded, but checked for correct answers as you go. Infitite retries, correct answers explained.
    - Frequency: Once at end of course.
7. Capstone
    - Description: Optional larger project, combining all skills or knowledge from course. Only necessary in courses with content that makes sense in a "hands-on" context.
    - Frequency: Course finisher for courses that are about a "hand-on" skill
8. Quiz
    - Description: Short knowledge check between readings or videos. Should only be between 1 and 3 questions.
    - Frequency: At least 2 per course, not within the same module
